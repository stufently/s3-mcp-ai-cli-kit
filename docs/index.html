Как начать

01

Соберите бинарь

Клонируйте репозиторий провайдера. До первого релиза используйте Docker-сборку из его README.

02

Настройте доступ

Создайте S3-ключ в своём облаке и сохраните его через auth set. Выберите бакет и ограничьте префикс.

03

Подключите MCP

Установите конфигурацию Claude Code, Cursor или Codex. Начните со списка объектов и чтения.

Пример подключения: Яндекс Облако + Codex

bash scripts/go.sh go build -o yandex-s3 ./cmd/yandex-s3
./yandex-s3 auth set
./yandex-s3 mcp install --client codex

Команды запускаются из корня клонированного yandex-s3-mcp-ai-cli. Для запросов в облако нужен ваш S3-ключ; ввод auth set скрывает секрет.

Статус проекта. Код и проверки на эмуляторе опубликованы. Живые проверки каждого облака ещё ожидают ключа владельца; релизы бинарей, OCI-образы и публикация в MCP Registry отложены. Профили и их ограничения описаны в репозиториях. TASKS.md →

Вопросы перед подключением

Какие S3-провайдеры входят в семейство?

Selectel, Яндекс Облако, VK Cloud, Cloud.ru Evolution, Timeweb Cloud, MWS Cloud Platform и Beget. У каждого собственный бинарь, профиль и документация.

Как подключить S3 к Claude Code, Cursor или Codex?

Соберите бинарь своего провайдера, сохраните ключ через auth set и выполните mcp install для выбранного клиента. Команды и расположение конфигурации указаны в README каждого проекта.

Может ли AI-агент удалять мои файлы?

MCP по умолчанию предоставляет только чтение. Запись, удаление и администрирование включаются отдельно; опасные действия проходят настроенную политику подтверждения. Дополнительно ограничьте права S3-ключа, бакет и префикс.

Это замена aws-cli или rclone?

Проекты добавляют MCP-инструменты, skill и контроль доступа для AI-агентов. CLI подходит для операций с объектами и потокового восстановления; aws-cli и rclone остаются отдельными инструментами автоматизации.

Все ли API одинаково доступны во всех облаках?

Нет. Инструменты регистрируются по возможностям профиля. Например, у Beget выключены bucket API и внешний presign, а профиль Cloud.ru относится к Evolution. Проверяйте compat и статус живых тестов.

Где посмотреть цены и сроки presigned-ссылок?

В исследовании своего провайдера со ссылками на официальные документы. Цены и неподтверждённые значения помечены в репозиториях; каталог не служит тарифным предложением.
