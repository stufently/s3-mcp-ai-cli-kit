# Статус

## Общий модуль

- Создан публичный репозиторий; перенесены общие пакеты и принятые защитные тесты Selectel.
- Загрузка YAML отделена от встроенных профилей; skill генерируется из общего шаблона.
- Добавлены отказ без S3 I/O при неподдерживаемых conditional writes/delete и матрица регистрации: 256 сочетаний capabilities × 8 уровней × наличие FILE_ROOT.
- Завершено: Docker build/vet/race, golangci-lint, versitygw (включая выключенные возможности), MCP smoke для 8 уровней, мутационные ворота 87/87, signal/hash self-tests и actionlint.
- В работе: публикация Go-модуля v0.1.0 и перевод Selectel.
- Далее: Yandex → VK Cloud → Cloud.ru → Timeweb → MWS → Beget, затем очистка публичных документов Selectel.

## Живые проверки

Нужна живая проверка каждого облака с ключом владельца. Эмулятор проверяет реализацию, не фактическую поддержку условных заголовков, API и лимитов облака. Теги релизов провайдеров остаются отложенными.
