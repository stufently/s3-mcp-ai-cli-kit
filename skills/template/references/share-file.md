# Обмен файлом

Если capabilities.presign:false, не вызывай presign: запроси у владельца ссылку из панели или используй разрешённое скачивание. Следующие инструменты доступны только при presign:true.

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше {{presign_max_seconds}} секунд. Ограничение профиля может требовать живой проверки: {{presign_note}}. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
